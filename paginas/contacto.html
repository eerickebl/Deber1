Preguntas frecuentes

¿Me van a responder por correo?

No. Este sitio no envía correos: tu mensaje solo se guarda en la base de datos y se puede consultar en la página de Mensajes.

¿Qué pasa si me equivoco en un dato?

El servidor revisa cada campo antes de guardar. Si algo está mal, el mensaje no se guarda y se te indica qué corregir.

¿Qué pasa con tu mensaje?

  1. El formulario envía tus datos por el método POST.
  2. El servidor revisa que todos los campos sean correctos.
  3. Si todo está bien, el mensaje se guarda en la base de datos.
  4. Puedes ver todos los mensajes en la página de Mensajes.
